C Programming Learning
課題：find_min_positive
1. 問題

整数配列の中から、最小の正の数を探す関数を作成する。

2. 関数
int find_min_positive(int numbers[], int size)
3. 入力
{-10, 7, 3, -2, 15, 5, -8, 12}
4. 期待される結果
3
5. 条件
配列のすべての要素を調べる。
正の数だけを対象とする。
正の数の中から最小の値を探す。
見つけた最小値を関数の戻り値として返す。
配列と配列の要素数を引数として渡す。
